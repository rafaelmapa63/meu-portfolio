Um sistema visual para cinco páginas

Detalhes do Projeto

Empresa
Categoria UI & Web Design
Ano 2024

Adaptei o Design System oficial da Porsche para cinco páginas do Grupo BAMAQ, incluindo a criação de um comparador de veículos inédito no UI Kit da matriz. Fui responsável pela estrutura das páginas, desenho da interface e handoff para desenvolvimento.

1 mês

Prazo para padronizar dois sites, acrescentar três landing pages e criar um comparador ausente no UI Kit da matriz.

45 veículos

Modelos e versões reunidos em um comparador com preços e especificações organizados para consulta lado a lado.

9 dados por veículo

Combustível, ano, nome, valor, potência, aceleração, velocidade máxima, câmbio e tração organizados para comparação.

Projeto

CONTEXTO

O Grupo BAMAQ precisava padronizar os sites do Porsche Center BH e Salvador e as landing pages do Cayenne, Macan e Macan Elétrico conforme o Design System oficial da Porsche.

DESAFIO

Além de aplicar os componentes da matriz, era necessário criar um comparador de veículos que não existia no UI Kit. A nova interface precisava seguir a mesma linguagem visual das demais páginas.

Construção

BASE VISUAL

Estruturei as cinco páginas a partir dos componentes oficiais, adaptando a composição aos conteúdos de cada uma. Para desenvolver os elementos do comparador, estudei a construção do kit e segui suas referências de tipografia, espaçamento e controles.

COMPARADOR

A versão final reúne dois veículos lado a lado, tanto no desktop quanto no mobile. Cada coluna tem seleção independente, imagem, preço e especificações na mesma sequência. Os dados ficam disponíveis para comparação simultânea, com acesso à cotação de cada modelo.

Priorização

PRIORIDADE

Comecei entendendo o Design System da Porsche, analisando o UI Kit e separando os elementos necessários. Depois, defini a estrutura das cinco páginas e apliquei o design. Deixei o comparador para o final porque essa parte exigia mais tempo e concentração para chegar a uma solução funcional e fácil de cadastrar.

FICOU DE FORA

Removi uma camada de personalização que não era necessária para o projeto. As duas páginas institucionais passaram a compartilhar uma estrutura, enquanto as três landing pages de veículos usaram outra. Em cada grupo, o conteúdo mudava sem exigir uma composição exclusiva para cada página.

RESULTADO

A decisão de compartilhar as estruturas foi minha. Essa organização permitiu concluir as cinco páginas dentro do prazo, manter consistência entre as entregas e facilitar a manutenção, reservando o tempo necessário para desenvolver o comparador.

Entrega

PUBLICAÇÃO

As cinco páginas foram publicadas e a entrega foi aprovada pela matriz. Os sites das concessionárias e as páginas de modelos passaram a compartilhar a linguagem visual oficial da Porsche, incluindo o novo comparador de veículos.

HANDOFF

Organizei o Figma em páginas separadas, com os componentes usados no projeto, e disponibilizei a documentação oficial do Design System da Porsche à equipe de desenvolvimento.
